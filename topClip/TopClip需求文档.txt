一、项目概述
1.1 产品定位
轻量化 Windows 剪贴板增强工具，弥补系统原生剪贴板仅保存单条内容的缺陷，集成历史记录、内容固定、全局窗口置顶、数据持久化、多主题切换能力，搭配现代化渐变 UI，主打高颜值、高实用性。
1.2 核心目标
支持最低 30 条剪贴板历史记录存储；
实现单条内容钉住锁定，避免被新记录覆盖；
窗口永久悬浮于所有窗口最顶层；
程序正常 / 异常关闭后，重启完整恢复所有数据与配置；
内置多套预设主题，支持浅色 / 深色模式切换；
最终编译为免安装、无依赖的 Windows 可执行程序。
二、全局通用规则
仅捕获文本类剪贴内容（纯文本、网址、代码文本），图片 / 文件类不做处理；
所有配置、历史数据实时落地本地文件，保障异常场景数据不丢失；
界面全程采用现代化设计，强制使用渐变配色，色调协调统一；
所有开关、状态、布局参数均支持持久化，重启不重置。
三、详细功能需求（按模块划分）
模块 1：剪贴板历史记录
功能描述
全局监听系统剪贴板，自动收录复制的文本内容，生成可视化历史列表。
执行规则
容量上限：列表最大存储 30 条 记录，不可超出；
排序规则：新复制内容自动插入列表顶部；
内容去重：短时间内重复复制相同文本，仅保留最新单条记录；
淘汰逻辑：列表满 30 条时，仅删除最早的未钉住内容；已钉住内容永久保留，不参与淘汰；
交互动作：点击列表内任意条目，自动将该内容重新复制到系统剪贴板。
模块 2：内容钉住（锁定）
功能描述
对单条历史记录进行锁定，保护内容不被清理，同时做视觉区分。
执行规则
界面元素：每条记录右侧设置钉住图标（开关控件）；
状态切换：点击图标切换「钉住 / 取消钉住」，即时生效；
视觉区分：已钉住条目使用专属底色 / 图标高亮，与普通条目明显区分；
列表排序：所有已钉住条目统一置顶排列，未钉住条目在下方；
数据持久化：钉住状态永久保存，重启程序自动恢复。
模块 3：窗口全局悬浮置顶
功能描述
控制程序窗口层级，实现桌面全局置顶悬浮。
执行规则
入口：软件顶部设置「置顶」开关按钮；
层级逻辑：开关开启 → 窗口固定在所有桌面窗口最上层；开关关闭 → 恢复普通窗口层级；
窗口操作：支持鼠标拖拽移动窗口、手动缩放窗口大小、最小化；
状态持久化：置顶开关状态、窗口坐标、窗口尺寸全部保存，重启自动还原。
模块 4：数据 & 配置持久化（异常恢复）
功能描述
适配程序正常关闭、强制终止、崩溃异常等场景，保证数据不丢失。
需持久化的内容清单
全部剪贴板历史记录（文本、创建时间）；
每条记录的钉住状态；
当前启用的主题、浅色 / 深色模式；
窗口置顶状态、窗口位置、窗口尺寸。
存储规则
存储文件：程序同级目录下 config.json；
写入机制：实时增量写入 + 程序退出全量写入（双重防丢失）；
容错处理：config.json 损坏 / 缺失时，程序正常启动，初始化空白列表 + 默认主题，无崩溃。
模块 5：主题配色 & 深浅模式
功能描述
内置多套预设主题，每套主题配套浅色、深色双模式，支持一键切换。
执行规则
入口：软件顶部设置「主题设置」按钮，点击展开主题选择面板；
切换效果：选择主题 / 深浅模式后即时生效，无需重启程序；
模式定义
浅色模式：浅底色 + 深色文字，渐变色调明亮；
深色模式：深底色 + 浅白色文字，低亮度护眼，渐变偏暗调；
持久化：当前选中的主题、深浅模式状态，重启保留。
强制预设主题（共 5 套，全部实现）
静谧蓝：浅蓝→深蓝 线性渐变
活力紫：淡紫→深紫 线性渐变
极简灰：浅灰→深灰 线性渐变（商务风格）
暖橙：浅橙→橘红 线性渐变
暗夜黑：深色系渐变（主打深色模式）
四、UI 视觉规范（强制落地）
4.1 整体风格
现代化 Windows 极简风格，卡片式布局、大圆角控件，无冗余元素，适配 Win10/Win11 原生视觉体系。
4.2 渐变要求
应用范围：标题栏、功能按钮、记录卡片、主题面板均使用线性渐变；
过渡要求：同主题内色彩过渡自然，无刺眼色差；
悬浮元素：弹窗、按钮 hover 状态增加轻微透明度，提升质感。
4.3 页面固定布局
顶部区域：软件名称 + 置顶开关 + 主题设置按钮；
中间主区域：剪贴板历史记录列表（单条为独立卡片）；
单条卡片：文本内容 + 钉住图标；
底部区域：状态提示（当前记录总数、模式标识）。
五、数据结构定义（config.json）
文件路径：程序根目录 /config.json，严格遵循以下字段格式，不可增减字段
json
{
  "windowInfo": {
    "topMost": true,
    "x": 100,
    "y": 100,
    "width": 400,
    "height": 500
  },
  "themeInfo": {
    "themeName": "静谧蓝",
    "darkMode": true
  },
  "clipHistory": [
    {
      "id": 数字ID,
      "content": "剪贴板文本内容",
      "pin": 布尔值(是否钉住),
      "createTime": "时间戳字符串"
    }
  ]
}
补充约束：clipHistory 数组最大长度 = 30。
六、非功能技术约束
系统兼容：完整适配 Windows 10（1903 及以上）、Windows 11 所有版本；
性能指标：剪贴板监听无卡顿，程序后台内存占用 ≤ 80MB；
稳定性：连续运行 24 小时无崩溃、无内存泄漏；强制关闭 / 异常断电后数据完整；
包体要求：最终 TopClip.exe 单文件体积 ≤ 80MB；
运行权限：普通用户权限即可启动，无需管理员权限；
代码规范：代码添加必要注释，目录分层清晰，便于后续维护。
