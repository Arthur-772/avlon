# .tool — 共享工具目录(工具 / 运行时 / SDK 本体)

供 `E:\avlon` 下**所有子项目共用**的工具集中放这里。完整规则见根目录 `AGENTS.md` 第 4 节(本机文件,不入 git)。

## 放什么

- 便携版运行时:Node.js、JDK、Go 等(zip 解压即用的绿色版)
- uv 本体及其管理的 Python 解释器
- 各类 CLI / 构建工具

## 不放什么

- 环境配置、缓存、虚拟环境、凭据 → 放 `E:\avlon\.env`
- 只服务于单个子项目的东西 → 放那个项目自己的目录

## 规则

1. 主机没有的工具,优先装到这里;**便携版优先**,避免安装器、注册表、系统服务。
2. 新增 / 删除 / 升级任何工具后,必须同步更新本目录的 [MANIFEST.md](MANIFEST.md)。
3. 本目录内容不入 git(`README.md` 与 `MANIFEST.md` 除外)。
