# R 审查清单(标准输入)

> R 只读:ACCEPTANCE + 代码 diff + 本清单。**不读 B 的讨论过程**。
> 输出:问题清单,按【阻断 / 建议】分级,逐条给出位置与依据。

1. **验收覆盖**:ACCEPTANCE 每条都有实现与可复现的自测证据?
2. **规范符合**:AGENTS.md §2-§5,尤其主机保护红线与 git 红线?
3. **边界与错误路径**:空输入、极值、失败分支、并发/重入(如适用)?
4. **项目独立性**:未跨项目引用、未共享依赖清单(AGENTS.md §3.2)?
5. **文档回写**:CHANGELOG / ADR 与实际变更同步?
6. **安全**:无凭据/令牌硬编码,无敏感信息入日志?
7. **可维护性**:命名、重复代码、明显坏味道(仅【建议】级)。
