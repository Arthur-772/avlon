# Typora+ 产品需求文档（PRD）

版本：v0.1（待评审）
日期：2026-10-12
状态：等待用户拍板

## 1. 背景与定位

Typora+ 是一款专供个人使用的轻量级 Markdown 编辑器，定位是"优雅地打开和编辑 .md 文档"。它复刻 Typora 最有价值的部分（所见即所得、舒适的阅读体验、字号缩放等基础能力），同时去掉订阅、账号、云同步等冗余负担。

核心原则：

* 打开快、体积小、无登录、无订阅、无遥测。
* 所见即所得优先，源码模式作为补充。
* 所有配置与数据完全保存在本机。

## 2. 技术选型（需拍板）

### 事实说明

Typora 本体基于 Electron + 自研闭源渲染引擎，其编辑内核无法直接复用。因此"同款"只能做到壳层相同（Electron），编辑内核需要选择开源替代。

### 推荐方案：Tauri 2 + Milkdown

| 组件    | 选型                      | 版本基准   | 理由                                                                   |
| ----- | ----------------------- | ------ | -------------------------------------------------------------------- |
| 桌面壳   | Tauri 2                 | 2.12.x | 复用系统 WebView2，安装包约 5\~10MB，内存占用显著低于 Electron，更符合"轻量"目标               |
| 编辑器内核 | Milkdown                | 7.22.x | 基于 ProseMirror + remark 的所见即所得 Markdown 编辑器，交互体验最接近 Typora，插件化架构便于裁剪 |
| 渲染增强  | remark 生态 + Shiki/KaTeX | 随内核    | 代码高亮、数学公式等按需加载                                                       |
| 打包    | Tauri NSIS              | 随壳     | Windows 标准安装包                                                        |

### 备选方案：Electron + Vditor

Electron 44.x + Vditor 4.0（所见即所得模式）。优点是与 Typora 壳层同款、Vditor 开箱即用功能更全；缺点是安装包约 80\~150MB、内存占用高，与"轻量定制"的目标相悖。

<br />

### 结论

推荐 Tauri 2 + Milkdown。若你对体积不敏感、更看重与 Typora 的技术一致性，可改用备选方案，功能清单不受影响。

## 3. 功能清单

### P0（首版必须）

| 编号   | 功能        | 说明                                       |
| ---- | --------- | ---------------------------------------- |
| F-01 | 打开 .md 文件 | 双击文件/拖拽进窗口/文件菜单打开；支持关联 .md、.markdown 后缀  |
| F-02 | 所见即所得编辑   | 标题、加粗斜体、删除线、列表、引用、链接、图片、行内代码、围栏代码块       |
| F-03 | 表格        | 可视化插入与编辑，支持对齐                            |
| F-04 | 任务列表      | 复选框可直接勾选并写回源码                            |
| F-05 | 数学公式      | 行内 `$...$` 与块级 `$$...$$`，基于 KaTeX        |
| F-06 | 代码高亮      | 常见语言高亮，支持语言标注                            |
| F-07 | 字号调节      | Ctrl + 滚轮 / Ctrl + 加减号缩放，记忆每窗口或全局设置      |
| F-08 | 源码模式切换    | Ctrl + / 快捷键，在 WYSIWYG 与纯 Markdown 源码间切换 |
| F-09 | 大纲面板      | 从 H1\~H6 生成目录，点击跳转，随光标高亮当前章节             |
| F-10 | 保存与防丢失    | Ctrl+S 保存；关闭未保存文件时弹窗确认；可选自动保存（默认开启，间隔可配） |
| F-11 | 亮暗主题      | 内置浅色/深色两套主题，跟随系统可选                       |
| F-12 | 中英文界面     | 默认中文，界面语言可切换                             |

### P1（第二迭代）

| 编号   | 功能            | 说明                                         |
| ---- | ------------- | ------------------------------------------ |
| F-13 | 导出 PDF / HTML | 无外部依赖的内置导出；Word/LaTeX 导出依赖 Pandoc，列为可选     |
| F-14 | 图片本地化         | 粘贴/拖入图片时自动复制到文档同级的 assets 目录并改写为相对路径（策略可配） |
| F-15 | 全局搜索          | 当前文件内搜索替换；文件夹内全文搜索                         |
| F-16 | 最近文件          | 记录最近打开的文档与文件夹                              |
| F-17 | 字数统计          | 字数、字符数、阅读时长，状态栏常显                          |
| F-18 | Focus 模式      | 当段落高亮、其余淡化（可选 Typewriter 打字机滚动）            |
| F-19 | 自定义 CSS       | 用户样式目录，放自定义 CSS 即可覆盖主题                     |

### P2（后续增强）

| 编号   | 功能    | 说明                    |
| ---- | ----- | --------------------- |
| F-20 | 文件树侧栏 | 打开文件夹后以树形浏览，新建/重命名/删除 |
| F-21 | 图床集成  | PicGo 协议，上传后替换为外链     |
| F-22 | 多标签页  | 单窗口多文档                |
| F-23 | 导出图片  | 整页导出为长图               |

## 4. 明确不做

* 账号体系、登录、订阅、授权校验
* 云同步、在线协作、评论
* 遥测与数据上报（零网络依赖，除更新检查外；更新检查也可关闭）
* 移动端 / Web 版

## 5. 非功能需求

* 安装包 ≤ 15MB（Tauri 方案），冷启动 ≤ 1 秒（普通 SSD）
* 1 万行级 Markdown 文档滚动与编辑不卡顿
* 所有用户数据（配置、主题、缓存）存于 `%APPDATA%/typora-plus`，卸载可留可清
* 隐私：默认无任何网络请求
* <br />

## 6. 验收标准（摘要）

1. 能直接打开本机任意 .md 文件并正确渲染标题/列表/表格/公式/代码块，与源码双向一致、无内容丢失。
2. Ctrl+滚轮 缩放即时生效且重启后保留。
3. 未保存关闭有确认；自动保存可关。
4. 安装包体积与冷启动达标，且全程无网络请求（可抓包验证）。
